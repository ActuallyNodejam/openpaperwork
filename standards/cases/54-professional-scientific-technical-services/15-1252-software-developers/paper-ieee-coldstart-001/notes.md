# paper-ieee-coldstart-001 - layout and licence

The starter uses the IEEEtran class that ships with the TeX distribution: CTAN package
ieeetran 1.8b, LPPL 1.3, Copyright 2001-2015 Michael Shell, read today at
https://ctan.org/pkg/ieeetran. Nothing is copied from the IEEE template files; the class
provides the two-column layout, the Roman-numeral headings and the reference style.

Built with the fork skills/paper/build_paper.py, which found tectonic 0.17.0 on the box.
The page is US Letter (612x792 pt), as the class sets for conference mode.
