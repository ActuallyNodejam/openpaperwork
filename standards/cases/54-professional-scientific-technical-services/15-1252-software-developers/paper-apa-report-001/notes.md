# paper-apa-report-001 - layout and licence

APA Style is a work of the American Psychological Association. The guideline in this pack
paraphrases the rules and links to the free APA Style pages; it copies no text from the
Publication Manual and is not endorsed by the APA. The reference style file apa.csl is
copied verbatim from the CSL styles repository under CC BY-SA 3.0 (see its NOTICE.md).

The document is built with python-docx: 1 inch margins, Times New Roman 12 pt, double
spacing, a student title page, centred bold Level 1 headings, a flush-left bold Level 2
heading, first-line indents of 0.5 inch and hanging indents on the reference list.
