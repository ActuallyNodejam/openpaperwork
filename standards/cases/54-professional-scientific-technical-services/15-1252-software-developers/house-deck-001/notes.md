# house-deck-001 - the creative family, script-graded

The house layout is one 12-column grid with fixed zones, and the model picks a page type
and fills the slots rather than designing. The rules here are the ones a script can read
off the file: the page count, the type floor, one accent colour, and every number tracing
to the data. The deck's own layout checks (boxes, columns, padding, chart geometry) need
the browser and live in the house-layout folder; this case is the checked half.
