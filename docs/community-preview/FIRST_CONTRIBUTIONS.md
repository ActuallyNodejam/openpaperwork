# Small contributions with a clear purpose

Ideas for a first change. Scoped ones are open as issues labelled `good first issue`, and new
standards as `standard`.

| Task | Contribution | What would demonstrate improvement |
| --- | --- | --- |
| A brief should be easy to scan | Improve heading and action-table guidance | Rendered before/after pages plus unchanged facts |
| A budget should stay correct when edited | Add spreadsheet recalculation evidence | Change a quantity and verify the dependent totals |
| A deck should survive a factual correction | Add a stale-number check across slide text and chart data | A regression fixture that catches the old value |
| A person should ask naturally in their language | Translate one request and review its meaning | Equivalent objectives, dates and locale conventions |
| An example should work without hidden setup | Prove a clean Community first-task path | Setup steps, exact version, interruptions and output |
| A check result should be auditable | Add a renderer adapter to the checks | Reproducible pages and versioned rendering evidence |

Before implementing a new checker, write the failure it should catch. Do not
turn a preferred phrasing or an exact internal tool sequence into a requirement
unless the person actually asked for it.
