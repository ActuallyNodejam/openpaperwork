# _shared

Support files for the OpenPaperwork packs: the shared letter, page and number code they import. Never a task on its own; the packs read it from here.

`npx skills add` and `portable-pack/install.sh` put this folder beside the packs, where their
scripts look for it (`<skills>/_shared`). Leave it there; nothing in it is a task to start.
