# HTML deck

A deck that is sent or presented is made with `business-deck`: it writes the pages as HTML, prints them to a PDF with the app's own browser engine, and writes an editable PowerPoint file when asked.
The scripts in this folder stay for the house-deck check and its cases; nothing new starts here.
